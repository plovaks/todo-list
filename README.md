# Список дел 

## Стек
**React**
**TypeScript**
**HTML/CSS**

## Функциональность
1. Добавление задачи через поле ввода и кнопку.
2. Переключение задачи между выполненной и невыполненной.
3. Удаление задачи.
4. Фильтрация: все, активные, выполненные.
5. Сохранение задач в localStorage: после обновления страницы они должны оставаться.
Пустую задачу или задачу из одних пробелов добавить нельзя. Выполненные задачи должны
визуально отличаться от активных.

Стили реализовала с помощью ИИ для ускорения разработки
